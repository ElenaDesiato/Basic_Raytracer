# Basic Raytracer

This is **Basic Raytracer**, a C++ implementation of a minimal ray tracing engine inspired by [Ray Tracing in One Weekend](https://raytracing.github.io/books/RayTracingInOneWeekend.html) by Peter Shirley, Trevor David Black, Steve Hollasch.

This project is an exploration of essential graphics programming concepts, computational geometry, and modern C++ practices, started after a course did a quick introduction on raytracing and I wanted to do more.

---

## 🛠️ Features

- **Ray-Sphere Intersection**
- **Diffuse (Lambertian) Material**
- **Metallic Material**
- **Simple Camera Model**
- **Random Scene Generation**
- **Anti-Aliasing (Supersampling)**
- **Recursive Ray Tracing**

---

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ElenaDesiato/Basic_Raytracer.git
   cd Basic_Raytracer
   ```

2. **Build the project:**
   ```bash
   make      # or use your preferred C++ compiler
   ```

3. **Run the raytracer and save the output:**
   The raytracer prints the image in PPM format to standard output. To save the output as a file:
   ```bash
   ./raytracer > output.ppm
   ```
